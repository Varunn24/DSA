# Data Structures & Algorithms – Java Implementations

This repository contains my personal collection of DSA programs written in Java. All files are simple, clean implementations focused on understanding core concepts. No AI-generated wording, no extra notes — just a human-written explanation of what the project includes.

---

## Included Java Files

These are the implementations currently in the repository:

* **AVL.java** – Self-balancing AVL Tree implementation
* **BinarytreeA.java** – First version of Binary Tree (basic functions and traversals)
* **BinarytreeB.java** – Second version of Binary Tree with alternative logic
* **BST.java** – Binary Search Tree (insert, delete, search, traversal)
* **BST2.java** – Another BST version with updated or different methods

You can add more files anytime as your DSA practice continues.

---

## How to Run the Programs

Make sure you have Java installed. Then open a terminal inside the folder where the `.java` files are saved.

### Compile all Java files

```bash
javac *.java
```

### Run any file that has a `main` method

```bash
java ClassName
```

Example: if `BST.java` has a main method inside class `BST`, run:

```bash
java BST
```
